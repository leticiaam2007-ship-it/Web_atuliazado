Comandos GIT

  • gir init : Cria um repositório
  • git add [file] : Adiciona um arquivo no stage
  • git status : Exibe o estado do repositório
  • git commit -m "msg" : Cria um commit
  • git log : Exibe os commits do repositório da branch atual;
  • git checkout referencia : Recupera o conteúdo da referencia para WK
  • git remote add nome url : Definir um repositório remoto
  • git push url branch : Envia a branch para o repositório remoto
  • git log --oneline : Exibe os commits do repositório da branch atual de forma simplificada
  • git reset referencia --hard
  • git checkout -b novabranch [referencia] : Cria uma nova branch
  • git branch --all : Mostra as branchs remotas que você tem no repositório
  • git checkout -b branchnome origin/branchnome : Move para a branch que ja existe no seu repositório
  • git push origin --all : Da um push no codigo, joga tudo pro repositorio

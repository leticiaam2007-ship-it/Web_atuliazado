O que é HTML?

O HTML é uma lingugaem de marcação,ele não é uma linguagem de programação. Ele é semantico ou seja tem forma e signififado,um exmeplo : Para colocar um termo em negrto da forma semantica certa com um valor e sgnificado é utiliado a tag Strong já para deixar soemnte com a forma sem significado (sem semantica) utilizaresmos a tag B.

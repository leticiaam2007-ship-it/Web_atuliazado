Entendendo o CSS

Uma regra CSS é o que usamos para estilizar o HTML. Ela tem três partes:

  • Seletor: Quem a regra atinge (ex: tag, classe ou ID).
  • Propriedade: O que queremos mudar (ex: cor, tamanho).
  • Valor: A configuração que damos (ex: azul, 20px).

O que é JavaScript?

JavaScript foi criado para deixar as páginas da internet mais interativas e dinâmicas. Com ele é possível criar animações, validar formulários e responder ações do usuário.

O JavaScript pode ser executado no navegador, como Chrome e Firefox, ou no servidor, utilizando tecnologias como Node.js.

No navegador, o JavaScript funciona em um ambiente chamado sandbox, que limita o acesso ao sistema do computador para oferecer mais segurança.

Alguns objetos globais importantes do JavaScript são: document (manipula a página HTML), console (mostra mensagens no console) e alert (exibe caixas de aviso).

Prova de Programação para Web da Letícia

A baixo segue a listagem para todas as resoluções das questoes da prova

  1. Questão 1

    • O que é HTML?
    • Qual o papel dele na Web?
    • Documento HTML5 nesse arquivo contém:
      • Estrutura mínima;
      • Um header,main e footer;
      • Um parágrafo;
      • Uma lista não ordenada.

    • Questão 2

      • Estrutura e sintaxe do CSS
        • Uma pseudo classe (:hover, :first-child, etc.);
        • Um pseudo elemento (::before, ::after, etc.);
        • Uma animação simples (usando @keyframes), aplicada a algum elemento, por exemplo, um botão que muda de cor ao passar o mouse.

    • Questão 3

      • Reproduza as seguintes bandeiras apenas com HTML e CSS (sem imagens), utilizando divs e Flexbox ou Grid:
        • França → 3 faixas verticais iguais (azul, branco, vermelho);
        • Alemanha → 3 faixas horizontais iguais (preto, vermelho, amarelo);
        • Japão → fundo branco e círculo vermelho centralizado.
